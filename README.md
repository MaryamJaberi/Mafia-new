# میز خدا — دستیار گردانندهٔ مافیا

ابزاری برای کسی که بازی مافیا را می‌گرداند: ساخت بازی، پخش نقش، ترتیب بیداری شب، رأی‌گیری و ثبت اتهام‌ها، همه روی یک گوشی.

نسخهٔ زنده: https://maryamjaberi.github.io/mafia/

## چه دارد

- سناریوهای آماده از ۶ تا ۱۸ نفر (کلاسیک، پدرخوانده، زودیاک، بازپرس، تکاور و ناتو و …)
- راهنمای گام‌به‌گام شب و روز برای گرداننده
- جدول و نمودار اتهام‌ها
- صدای شب
- پیوستن بازیکن‌ها با کد QR و مشاور هوش مصنوعی: فقط وقتی سرور روشن است

## دو شکل اجرا

| شکل | دستور | چه کار می‌کند |
|---|---|---|
| با سرور | `npm run dev` | همه‌چیز، از جمله اتاق چنددستگاهی و مشاور |
| بدون سرور (گیت‌هاب) | `npm run build:pages` | فقط حالت تک‌دستگاه؛ اتاق و مشاور خاموش‌اند |

## تست‌ها

این مخزن هنوز تست خودکار ندارد. فقط `npm run lint` (بررسی نوع‌ها) هست. تست‌هایی که باید نوشته شوند، به ترتیب اهمیت:

1. یک بازی کامل کلاسیک ۱۰ نفره: شب، روز، رأی، پایان و اعلام برنده
2. شرط بُرد برای هر سناریو (شهر، مافیا، نقش مستقل)
3. ترتیب بیداری شب برای هر سناریو، در برابر مرجع قانون‌ها
4. صفحهٔ ساخت بازی روی گوشی ۳۹۰ پیکسلی از عرض بیرون نزند (در نوامبر ۲۰۲۶ رفع شد)
5. در نسخهٔ بدون سرور، دکمه‌های اتاق و مشاور پیام روشن بدهند
